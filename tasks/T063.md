# T063

Ground async, structured concurrency, and cancellation in a smaller executable v1 model.

## Goal

Turn the current high-level concurrency intentions into a narrower model that could actually guide implementation.

## Review Focus

* decide how much async belongs in v1
* decide how much structured concurrency belongs in v1
* decide whether cancellation semantics are concrete enough to keep or should be deferred
* ensure the model does not imply hidden runtime behavior while still being implementable

## Expected Output

* a reduced and executable v1 concurrency model
* explicit decisions on what is deferred
* spec updates needed in `spec/LANGUAGE.md`, `spec/IMPLEMENTATION.md`, and related docs
