# T062

Settle trait and method receiver semantics for v1.

## Goal

Define what `self` means in Ferox methods before deeper trait and semantic implementation work begins.

## Review Focus

* decide whether method receivers support by-value, shared-borrow, mutable-borrow, or multiple explicit forms
* check how the chosen receiver model interacts with ownership, mutation, trait ergonomics, and API clarity
* keep the receiver surface small enough for v1 while still supporting useful method design

## Expected Output

* a concrete receiver model for v1
* syntax and semantic rules for method receivers
* spec updates needed in `spec/LANGUAGE.md` and any related docs
