# T061

Narrow the ownership model to a smaller v1 surface.

## Goal

Reduce the number of overlapping ownership and resource-management mechanisms Ferox expects users to learn in v1.

## Review Focus

* reevaluate the combination of lexical borrowing, arenas, shared ownership, shared mutation wrappers, and synchronized sharing
* decide which pieces are truly core to Ferox's identity and which should be cut, narrowed, or deferred
* keep the ownership story coherent enough to support the claim that Ferox is smaller than Rust

## Expected Output

* a reduced v1 ownership surface
* a clear statement of what stays, what is simplified, and what is deferred
* spec updates needed in `spec/LANGUAGE.md`, `spec/VISION.md`, and related docs
