# T065

Research high-value language and compiler ideas from existing work that Ferox may be able to adopt selectively.

## Goal

Find ideas that are genuinely strong, still not mainstream, and potentially useful for Ferox without importing unnecessary complexity.

## Research Filter

* prefer primary sources
* prefer ideas that strengthen Ferox's core identity
* prefer ideas that improve compiler/runtime/tooling architecture without forcing a larger source-language surface
* treat new semantic subsystems as high-risk by default

## Expected Output

* a curated list of external ideas worth studying
* a shortlist of ideas worth deeper Ferox-specific analysis
* notes on what should be adopted, studied only, or rejected
