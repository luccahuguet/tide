# T071

Run an implementation go / no-go review against the narrowed v1 direction.

## Goal

Decide whether Ferox is ready to start implementation work now, and if so, which parts are actually safe to begin.

## Review Focus

* whether the narrowed v1 is stable enough for the Rust bootstrap to start
* which implementation layers are ready now
* which implementation layers should still wait
* whether the current implementation plan is honest about remaining semantic risk

## Expected Output

* a concrete verdict: go, conditional go, or no-go
* a list of implementation work that is allowed now
* a list of implementation work that should still be deferred
* the main remaining risks that could still force redesign
