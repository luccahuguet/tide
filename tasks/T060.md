# T060

Decide whether the general effect-set model belongs in Ferox v1.

## Goal

Resolve whether explicit effect sets such as `![io, async]` should remain part of the initial language design or be deferred.

## Review Focus

* determine whether the effect system is carrying too much semantic weight for v1
* separate what Ferox actually needs for v1 from what is attractive in a more ambitious long-term design
* decide whether `async`, `io`, and other effectful behavior should use a narrower surface than a general effect-set model

## Expected Output

* a keep, simplify, or defer decision for effect sets
* a concrete replacement plan if the current model is cut or narrowed
* spec updates needed in `spec/LANGUAGE.md`, `spec/VISION.md`, and related docs
