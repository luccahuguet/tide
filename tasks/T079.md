# T079

Make `br` the canonical tracker for open Ferox work and keep `TASKS.md` as the completed-task archive.

## Goal

Collapse the earlier hybrid workflow into a single consistent rule:

* open work lives in `br`
* task meaning lives in `tasks/T###.md`
* completed numbered tasks are archived in `TASKS.md`

## Expected Output

* repository rules updated to reflect `br` as the source of truth for open work
* committed `.beads` state suitable for sharing in git
* `TASKS.md` reduced to an archive instead of a live task board
* no contradictory documentation about which system is canonical
