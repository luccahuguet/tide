# T068

Analyze whether narrow typestate or protocol-checking ideas should influence Ferox.

## Goal

Determine whether Ferox should adopt a small form of typestate or protocol-state checking without turning it into a large new language subsystem.

## Review Focus

* protocol correctness value
* interaction with Ferox's ownership and type-system goals
* whether this should be a later language feature, a lint, a library pattern, or an analysis layer

## Expected Output

* a recommendation to adopt, adapt, defer, or reject
* a concrete suggestion for the smallest sensible Ferox form, if any
