### Tide

Tide is a design-first programming language project. `design/01-design.md`
is the decision record and owns every language decision; the chapters in
`design/` elaborate it and `design/reference.md` is the agent-loadable core
reference. `research/` holds cited evidence, `reviews/` the adversarial
reviews, and `trials/` the learnability experiments. `archive/v0-design/` holds
the superseded first design; `crates/` holds an early bootstrap scaffold from
it.

### Governance

`GOVERNANCE.md` binds every change:

- production code is agent-produced; mark any human-written production code as
  an explicit exception;
- no PR merges without an AI supervisor verdict, run as `AI_SUPERVISOR.md`
  describes;
- substantial language or toolchain additions pass the low-entropy design
  admission filter.

### Beads

`br` tracks open work. Follow `BR_WORKFLOW.md` for `T###` task mapping, the
`TASKS.md` archive, and which `.beads/` files to commit.

### Verification

`scripts/test/e2e_workspace_smoke.sh` runs `cargo test --workspace` and the
CLI smoke checks of the early bootstrap scaffold, whose binary keeps
the working name `ferox`.
