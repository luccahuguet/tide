### Tide

Tide is a design-first programming language project. `design/01-design.md`
is the decision record and owns every language decision; the chapters in
`design/` elaborate it and `design/reference.md` is the agent-loadable core
reference. `research/` holds cited evidence, `reviews/` the adversarial
reviews, and `trials/` the learnability experiments. `archive/v0-design/` holds
the superseded first design and its early Rust scaffold.

### Governance

`GOVERNANCE.md` binds every change:

- production code is agent-produced; mark any human-written production code as
  an explicit exception;
- no PR merges without an AI supervisor verdict. For code, tests, or scripts,
  converge (AP-PROOF-001) finishes the change first, and the supervisor then
  reviews the converged diff before merge; docs-only design work uses review
  rounds instead of converge;
- substantial language or toolchain additions pass the low-entropy design
  admission filter.

### Beads

`br` tracks open work. Follow `BR_WORKFLOW.md` for `T###` task mapping, the
`TASKS.md` archive, and which `.beads/` files to commit.

### Verification

The repository holds no production code until the v0 checker starts;
`spikes/` holds throwaway feasibility prototypes, run by their own scripts. Design changes are
checked by review rounds and learnability trials (`design/01-design.md` D0).

### Decisions

The owner sets scope, priorities, and direction (AP-SCOPE-001); technical
design decisions are the agent's. Do not ask the owner a technical question,
including a bead's "owner decision" or "stop and ask" on a design choice.
When in doubt, take a web research pass, then decide, record the decision
and its reasons on the bead and in its owning design document, and report
it.
