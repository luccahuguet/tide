## Blocking

1. **[P1] User code can call the runtime’s root-minting entry point.**  
   [walk.rs:124](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/walk.rs:124)

   Unlisted Tide std items default to admitted. Against the conformance facade, `pub fn forge() { let _ = std::__rt::root(); }` passes admission, including inside a test. ADMIT-1 explicitly excludes internal runtime entry points; RUN-1 relies on that exclusion.

   **Minimal patch:** reject direct access to the minting entry point, permitting only the call generated by the trusted entry-point lowering. Add negative direct-call and positive normal-entry-point regressions.

2. **[P1] Array conversions bypass the randomized-hasher prohibition.**  
   [policy.rs:202](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/policy.rs:202), [walk.rs:155](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/walk.rs:155)

   `HashMap::from([(1, 2)])`, `HashSet::from([1, 2])`, and array `.into()` pass admission. The pinned std’s array `From` implementations call `from_iter` internally, creating an OS-seeded `RandomState`. Their public bounds contain no `RandomState: Default` obligation for this walk to discover.

   This violates GLOBAL-5 despite direct `new()` and ordinary `collect()` being rejected.

   **Minimal patch:** deny these two selected std implementations. Test direct `From` and blanket `Into` routes through the facade.

3. **[P1] The obligation-depth limit silently admits unchecked behavior.**  
   [walk.rs:274](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/walk.rs:274)

   `Default::default()` for twelve nested one-element arrays around `RandomState` is rejected; thirteen nested arrays pass. The thirteenth obligation is discarded, allowing the forbidden random-key constructor.

   **Minimal patch:** make exhaustion fail closed, or traverse obligations without silently dropping the remainder. Retain cycle detection and add the thirteen-level regression.

4. **[P2] `ptr::eq` is rejected despite GLOBAL-4 explicitly admitting it.**  
   [policy.rs:66](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/policy.rs:66), [walk.rs:453](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/walk.rs:453)

   `pub fn same(a: &u8, b: &u8) -> bool { core::ptr::eq(a, b) }` produces FX0520 for both the function and its implicit raw-pointer coercion.

   **Minimal patch:** admit pointer equality and narrowly accommodate its reference coercions. Preserve rejection of user-exposed raw pointers and address observers. Add this positive case.

5. **[P2] Ordinary path operations fail because `OsStr` is unlisted.**  
   [policy.rs:174](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/policy.rs:174)

   `p.file_name()` is rejected for its inferred `OsStr` result; `p.as_os_str().to_str()` is also rejected. Reference §1 and 03 §1.1 explicitly preserve `OsStr`/`OsString`’s Rust API, which performs no I/O.

   **Minimal patch:** admit their audited canonical types and methods. Add a positive path-component case while keeping `Path`’s ambient filesystem methods rejected.

6. **[P2] The OS-error policy adds an unsupported API restriction.**  
   [policy.rs:180](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/policy.rs:180)

   `io::Error::from_raw_os_error(2)` is rejected. It constructs an error from a supplied integer; it does not read `errno`. The design excludes `last_os_error` and otherwise preserves `io::Error`’s API.

   The adjacent `raw_os_error` denial is likewise unsupported and targets the wrong defining path on this pin: the accessor lives in `core` and currently passes.

   **Minimal patch:** admit `from_raw_os_error`, remove the unsupported accessor denial, and test construction/access while preserving rejection of `last_os_error`.

7. **[P2] Inline assembly remains forbidden under an `unsafe` grant.**  
   [policy.rs:72](/home/lucca/pjs/lab/tide-fx-kw8.1/crates/tide-admit/src/policy.rs:72)

   An empty `unsafe { core::arch::asm!(""); }` receives FX0520 even with `--tide-grant=unsafe`. The blanket architecture denial introduces a restriction absent from UNSAFE-1; RUN-2’s acceptance table explicitly includes `asm!` under that grant.

   **Minimal patch:** add a grant-gated `core::arch::asm` entry before the broad denial. Test both grant states.

8. **[P2] The second pass can count a compiler crash as an expected rejection.**  
   [run.sh:114](/home/lucca/pjs/lab/tide-fx-kw8.1/conformance/run.sh:114), [run.sh:122](/home/lucca/pjs/lab/tide-fx-kw8.1/conformance/run.sh:122)

   **Minimal patch:** preserve each invocation’s actual status and fail on crashes or setup failures before aggregating expected compiler rejections. Add a small runner regression using a failing driver substitute.

9. **[P2] Cargo target overrides can make conformance test a stale driver.**  
   [run.sh:44](/home/lucca/pjs/lab/tide-fx-kw8.1/conformance/run.sh:44)

   The build honors `CARGO_TARGET_DIR`, but the runner executes `$ROOT/target/debug/tide-admit`. Cargo metadata confirmed the override changes the output directory. With an existing root binary, the runner can build the candidate elsewhere and test an older executable.

   **Minimal patch:** pass `--target-dir "$ROOT/target"` to the driver build, matching the path subsequently executed.
