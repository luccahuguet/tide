# Tark Spec Index

This repository now splits the specification into focused documents instead of keeping all language, tooling, and strategy material in one file.

## Current Status

The language is called **Tark**.

Current status:

* selected as the project name
* should still pass trademark and brand-conflict review before becoming final for public release
* `.tark` is the current preferred source file extension
* extension and branding still require final release-readiness review

## Main Documents

* [spec/VISION.md](./spec/VISION.md): project vision, priorities, positioning, and high-level design principles
* [spec/LANGUAGE.md](./spec/LANGUAGE.md): language rules, semantics, syntax, effects, concurrency, and error handling
* [spec/TOOLING.md](./spec/TOOLING.md): formatter, CLI, manifests, workspaces, and package-system design
* [spec/IMPLEMENTATION.md](./spec/IMPLEMENTATION.md): bootstrap and self-hosting strategy
