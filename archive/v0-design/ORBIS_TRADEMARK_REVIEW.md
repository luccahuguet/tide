# Orbis Trademark Review

This document records a first-pass trademark screening review for the name **Orbis**.

This is **not legal clearance**.

Review date:

* March 8, 2026

Current scope:

* United States
* Brazil
* first-pass screening based on publicly accessible trademark sources and linked public references

## Scope Note

Interpretation used for this review:

* the project is design-stage and globally oriented
* the user is based in Brazil
* this first pass therefore treats the United States and Brazil as the immediate target jurisdictions

## Summary

Current conclusion:

* `Orbis` does **not** look clean enough to treat as a low-risk public language mark
* the United States already has active exact `ORBIS` registrations and a new active exact `ORBIS` application in computer-hardware/software-related classes
* Brazil should not be treated as clear by default, and should be treated as a manual follow-up jurisdiction rather than assumed safe from the U.S. result alone

Current recommendation:

* do **not** assume `Orbis` is cleared for public launch
* do **not** spend on public launch assets under the assumption that the mark is legally safe
* if `Orbis` remains the chosen public name, get a real clearance review before launch, especially for Brazil and the United States

## Brazil Screening

### 1. Brazil requires its own search and cannot be inferred from U.S. results

Why it matters:

* INPI states that trademark rights are exclusive in Brazilian territory
* INPI also recommends prior searching before filing
* this means Brazil needs its own real clearance work rather than a U.S.-only conclusion

Sources:

* INPI FAQ on marcas: https://www.gov.br/inpi/es/servicios/preguntas-frecuentes/marcas
* INPI basic guide: https://www.gov.br/inpi/es/servicios/marcas/guia-basica
* INPI e-Marcas entry point: https://www.gov.br/inpi/pt-br/assuntos/marcas/e-marcas

### 2. First-pass public screening did not establish Brazil as clean

Observed risk:

* exact `Orbis` commercial use already exists in Brazil-facing markets
* public web evidence shows `Orbis` in live Brazil-facing branding and commerce
* this does not by itself prove a conflicting Brazil registration in the relevant software classes, but it is enough to reject any assumption of a clean field

Examples:

* `Orbis do Brasil`: https://orbisdobrasil.com.br/
* `Orbis` social-platform/company profile in Sao Paulo: https://www.thecompanycheck.com/company/b/orbis/9et9lsqnpkofwgfb1

### 3. International `ORBIS` registrations already designate Brazil

Notable record:

* `Orbis`
* WIPO application number `1645342`
* status shown as live
* Brazil is listed among designated jurisdictions

Why it matters:

* this is not a software registration, but it confirms the exact word is already being pursued internationally with Brazil coverage
* it increases clearance complexity for the exact mark in Brazil

Sources:

* WIPO/Global Brand Database entry point: https://www.wipo.int/en/web/global-brand-database
* secondary record summarizing the international filing: https://www.trademarkelite.com/wipo/trademark/trademark-detail/1645342/Orbis

## Practical Recommendation

For release planning:

* treat `Orbis` as legally sensitive rather than presumptively safe
* do not rely on the idea that Brazil makes the name materially easier
* if the project is serious about public launch, run a proper Brazil + U.S. clearance review before launch branding
